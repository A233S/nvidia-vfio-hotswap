# GPU Hot-Swap Scripts for Linux Gaming + VFIO Passthrough
# Linux 游戏 + VFIO 直通 GPU 热切换脚本

两个脚本，用于将 NVIDIA GPU 从宿主机动态解绑并直通给虚拟机（例如通过 Looking Glass 在 Windows VM 中玩游戏），会话结束后再干净地还原回宿主机，**全程无需重启**。

Two scripts to dynamically detach your NVIDIA GPU from the host and pass it through to a VM (e.g. for gaming in a Windows VM via Looking Glass), then cleanly restore it back to the host — **no reboot required**.

适用场景 / This is useful for:

- 平时在 Linux 下工作，偶尔需要 Windows VM / Game on Linux but need a Windows VM occasionally

## 使用方法 / Usage

```bash
# 将 NVIDIA GPU 从宿主机解绑，准备直通给 VM
# Detach NVIDIA from host, prepare for VM
sudo ./dnv.sh

# VM 会话结束后，将 GPU 还原给宿主机
# After your VM session ends, restore to host
sudo ./rnv.sh
```

## 配置说明 / Configuration

编辑 `~/.config/gpu-passthrough/config.sh` / Edit the config file:

```bash
GPU_PCI="0000:01:00.0"         # NVIDIA GPU 的 PCI 地址 / Your NVIDIA GPU PCI address
AUDIO_PCI="0000:01:00.1"       # GPU HDMI 音频（可选）/ GPU HDMI audio (optional)
EXTRA_PCI=""                    # 其他要直通的设备（USB、NVMe…）/ Other passthrough devices
KVM_MODULE="kvm_intel"         # Intel 用 kvm_intel，AMD 用 kvm_amd / or "kvm_amd"
KVM_NESTED="yes"
USE_KVMFR="no"                 # 使用 Looking Glass 则改为 "yes" / set "yes" if using Looking Glass
KVMFR_SIZE_MB="128"
DISPLAY_MANAGER="sddm"         # 显示管理器，Vulkan 检查失败时作为回退提示 / fallback hint if Vulkan still fails
```

用以下命令查找你的 GPU PCI 地址 / Find your GPU PCI address with:

```bash
lspci -D | grep -i nvidia
```

## 混合显卡笔记本注意事项 / Hybrid Laptop Tip

在 Intel/AMD 核显 + NVIDIA 独显的笔记本上，Vulkan 应用可能默认使用核显。Steam 游戏请在启动选项中添加：

On laptops with Intel/AMD iGPU + NVIDIA dGPU, Vulkan apps may default to the iGPU. For Steam games, add to Launch Options:

```
__NV_PRIME_RENDER_OFFLOAD=1 __VK_LAYER_NV_optimus=NVIDIA_only __GLX_VENDOR_LIBRARY_NAME=nvidia %command%
```

## 常见问题排查 / Troubleshooting

**`dnv.sh` 提示"模块仍在加载" — VM 无法启动 / `dnv.sh` says "module still loaded" — VM won't start:**

有进程仍在持有 GPU。用以下命令检查 / Some process is still holding the GPU. Check with:

```bash
sudo lsof /dev/nvidia*
```

常见原因：nvidia-persistenced、nvidia-powerd、gamemode、浏览器硬件加速。停止相关进程后重试。/ Common culprits: nvidia-persistenced, nvidia-powerd, gamemode, browser hardware acceleration. Stop them and retry.

---

**`rnv.sh` 报 "could not insert 'nvidia': No such device"：**

**`rnv.sh`: "could not insert 'nvidia': No such device":**

这意味着在设备还未出现在总线上时，模块就尝试加载了。脚本内部已通过在 PCI remove 之前加载模块来处理此问题。如果仍然出现，请检查配置文件中的 PCI 地址是否正确。

This means modules tried to load while devices were absent from the bus. The script handles this internally by loading modules *before* PCI remove. If you still see this, your config file may have a wrong PCI address.
